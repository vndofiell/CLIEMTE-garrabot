🛡️ LOSS VIRTUAL
Simula resultados antes de entrar de verdade
✅ Com Loss Virtual ATIVO:
  • Simula o resultado de cada tick sem entrar
  • Conta losses consecutivos
  • S• entra de verdade após N losses virtuais

🔵 Com Loss Virtual INATIVO:
  • Entra a cada sinal normalmente
⚡ COMPORTAMENTO AUTOMÁTICO APÓS DISPARAR:
  • Quando o LV atingir N losses virtuais → entra normalmente
  • Se PERDER → ignora seq_gatilho e entra em CADA TICK sem parar
  • Só volta ao modo LV normal após o primeiro WIN real
  • Não precisa de nenhuma configuração extra — é sempre assim
📊 FILTRO DE HISTOGRAMA
📊 SÓ entra quando WIN domina o volume:
  • Analisa os últimos N ticks (janela recente)
  • Calcula: %WIN − %PERDA
  • Libera APENAS se WIN superar PERDA pela margem configurada

  Ex: Over 5 | janela=30 | margem=+10%
  → WIN(6-9)=65%, PERDA(0-5)=35% → domínio=+30% ≥ +10% ✅
  → WIN=50%, PERDA=50% → domínio=0% < +10% 🚫
  → WIN=40%, PERDA=60% → domínio=−20% 🚫
Recomendado: 20–40 ticks
+10%
0% = empate libera | 10% = WIN precisa ter 10% a mais (recomendado) | 20% = muito restritivo
0 = desativa | 2 = padrão (bloqueia na 2ª perda seguida)
🟡 Camada 3 — Confirmação de liberação
Após bloquear, aguarda N wins nos últimos M ticks antes de liberar.
Evita a liberação falsa logo após uma sequência ruim.
Ex: M=5, N=3 → exige 3 wins nos últimos 5 ticks para liberar
